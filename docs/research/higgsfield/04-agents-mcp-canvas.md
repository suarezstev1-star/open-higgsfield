## 1. Frontend architecture

### Framework / routing / SSR
- **[O] TanStack Start + TanStack Router.** `iauAJ8LxZqM_9W6I.js` env block: ``TSS_SERVER_FN_BASE:`/_serverFn/` ``, ``TSS_ROUTER_BASEPATH:`/` ``, ``TSS_INLINE_CSS_ENABLED:`false` ``, ``BASE_URL:`https://assets.higgsfield.ai/tanstack/` ``, ``VITE_BLENDER_RUNNER_URL:`https://3d-scene-builder.higgsfield.ai` ``. History state uses `__TSR_key`.
- **[O] File-based route tree.** The main chunk defines routes as ``R(`/_private/supercomputer/memory`)({component:I(zH,`component`),pendingComponent:P})`` and then `.update({id:'/memory',path:'/memory',getParentRoute:…})`. 412 route IDs were extracted. Route groups include `/(public)`, `/_private` (auth-gated layout), `/(mobile)`, `/(action-redirects)`, `/(static)`, `/(redirects)`, `/(team-actions)` and `/(explore)`.
- **[O] Automatic route code-splitting.** ``codeSplitGroupings:[[`component`],[`errorComponent`],[`notFoundComponent`]]`` appears on routes such as `/_private/supercomputer_/embed`. Lazy loads are wrapped as `globalThis.__HF_MOBILE_CHUNK_OBSERVER__.load(...)` (421 chunks) with `__vite__mapDeps([...])`. That makes it a Vite build. The main chunk also has ``Md=`/api/route-preload-manifest` ``.
- **[O] Server functions** follow the pattern ``AN=Xi({method:`GET`}).handler(ca(`b50c7aac…437c`))``, which is createServerFn plus an RPC id of 64 hex characters. There are 19 unique ones (17 GET, 2 POST). Examples are the `/mcp` page loader, the `/mcp/$slug` skill loader (`jN`) and the bundles loader (`AN`).
- **[O] Build identity** comes from the `index.html` attribute `data-hf-chunk-observer`: `"buildId":"38611332905-1-production","commit":"6b9e90ec7b85ce88f92c44edc07c79a5b171ed66","assetBase":"https://assets.higgsfield.ai/tanstack/assets/"`.
- **[O] Auth: Clerk.** `index.html` loads `clerk.higgsfield.ai/npm/@clerk/clerk-js@6.32.1/dist/clerk.browser.js`. OAuth continues through `https://higgsfield.ai/_clerk/oauth/authorize/continue` (main chunk). There are `/oauth`, `/oauth/consent/` and `/_private/device` routes, plus `fnf-device-auth.higgsfield.ai`.

### State management
- **[O] TanStack Query** is the primary server-state layer: `queryKey` appears in about 630 chunks. Also seen: `ensureInfiniteQueryData` and `setQueryData` (agent history in `WD-8yPy3QNZ7ZOYj.js`), and the query key ``[`claudesfield-memories`]`` (`uWQIvnJ7wjcpIe51.js`).
- **[O]** Router state is read through `useRouterState`-style selectors, e.g. `b({select:e=>e.state.facelyWorkflowId})` in `ordcw14er2psRBxo.js`. Custom external stores are built on `useSyncExternalStore` (about 160 chunks). One example is the agent-session store in `Btstrp_JbJ7Uxzp9.js`: ``{folderId,chatId,mode,model,reasoning_effort,…status:`idle`}``, with modes ``new Set([`ask`,`auto`,`plan`])``.
- **[O] Zustand** appears only inside React Flow/xyflow (`uyjMhiQKh15l2pYD.js` "[React Flow]: … zustand provider") and in a devtools middleware (`uZmL358GHOgrIrIs.js`). Immer is present (3 chunks). ts-pattern `.with().otherwise()` is used heavily (about 254 chunks). Zod is used, including the AI SDK chunk schema.
- **[I]** There is no Redux, Jotai app store or XState as primary app state. The "redux" hits are third-party code.
