# 02 — Higgsfield generation pipeline (static analysis of shipped JS)

Scope: image / video / audio-speech / lipsync / motion / effects-presets / upscale / Soul & characters / avatars / Genjutsu / Katana / 3D / apps.
Method: static analysis only of `scratchpad/hf-assets/*.js` (no network). Chunk names below are abbreviated: `X` = `868a8dba-X.js`.
Labels: **OBSERVED** = literal in code (file + snippet); **INFERRED** = reasoned from observed code; **UNKNOWN** = not determinable statically.

Raw extraction dumps (generated by `scratchpad/tools/*.js`) are in `findings/02-raw/`:
`_jobsettypes.txt` (217-entry job-set-type enum), `_jobdefs.txt` (135 job-definition chunks with credit formulas),
`_video_model_fields.txt` / `_fields_video.txt` / `_fields_image.txt` (form-field descriptors), `_map_video.txt`, `_map_image.txt`.

## 0. TL;DR

- **API gateway**: every generation call goes to `https://fnf-api-gw.higgsfield.ai/fnf` (OBSERVED `QhqiFCLt1Ukztv0Y`: `yb=(vb=\`https://fnf-api-gw.higgsfield.ai/fnf\`)`; axios-like client `ofe.create({baseURL:gb(),...})`). Auth: `Authorization: Bearer <Clerk JWT>`, optional `hf-workspace-id`, `Accept-Language`, `hf-surface` headers. DataDome bot protection (`dd.higgsfield.ai`) wraps gateway calls.
- **Upload**: `POST /media/batch` (images) or `POST /video` / `POST /audio` → presigned `upload_url` → browser `PUT` to object storage (S3; multipart via Uppy AwsS3 plugin for big files) → `POST /media/{id}/upload` (or `/video/{id}/upload`, `/audio/{id}/upload`) to confirm, which triggers **NSFW + IP (copyright/likeness) checks**.
- **Submit**: `POST /jobs/{route}` or `POST /jobs/v2/{job_set_type}` with body `{params:{...}, use_unlim, use_free_gens, parent_id, confirmation_token, ...}` → response `{job_sets:[{id, type, params, jobs:[{id,status,results:{raw,min,thumbnail}}]}]}`. Some flows use `/chains/*` endpoints (multi-step server-side pipelines).
- **Completion**: hybrid **SSE** (`https://fnf-api-gw.higgsfield.ai/fnf-notification/notifications/stream`, event `job:status_changed`) **+ polling** `POST /jobs/status-batch {ids:[...]}` (every 5 s, relaxed to 30 s while SSE is open; batches of 100).
- **Statuses**: `waiting | queued | in_queue | pending | in_progress | processing | ip_detect | dna | script | visuals | vision | flow | completed | failed | nsfw | ip_detected | canceled | timed_out/timed-out`.
- **Results**: `results.raw.url` / `results.min.url` / `thumbnail_url`; user outputs observed on `https://d8j0ntlcm91z4.cloudfront.net/user_<clerkId>/hf_<YYYYMMDD>_<HHMMSS>_<uuid>`; resized through `https://higgsfield.ai/cdn-cgi/image/...` (Cloudflare Images).
- **Catalog**: 217 job-set types; ~45 image model ids and ~85 video model ids in the studio pickers (Kling 2.5→3.0/O1/O3, Seedance Pro/1.5/2.0/2.5, Veo 3/3.1, Sora 2 family, Wan 2.2→3.0, MiniMax Hailuo 02/2.3/H3, Grok Imagine, Gemini Omni, FLUX.2/3, Nano Banana 1/2/Pro/2.1/Lite, Seedream 4→5, GPT Image 1.5/2/2.5, Soul 1/2/Cinema, Recraft, Ideogram, Z-Image, Reve, Kling O1 image, HappyHorse, Higgsfield Lite/Standard/Turbo, Cinema Studio 2.5→4.0…).
- **Credits**: authoritative prices come from the server (`GET /job-sets/costs`, `POST /jobs/{route}?dry_run=true`, `pricing.higgsfield.ai`); client holds many fallback tables (quoted below).

## 2. Generation job lifecycle

### 2.1 Upload of inputs — OBSERVED

Simple path (`-z2V5qzcrviH-uGq`, `RKpCrebWFpypqouZ`):
1. Image: `POST /fnf/media/batch {mimetypes:[type], source:'user_upload', surface, force_ip_check}` → `[{id, url, upload_url}]`. (Hidden assets: `POST /media {mimetype, is_hidden:true}`.)
   Video: `POST /video {mimetype, force_ip_check}` → `{id, url, upload_url, content_type, thumbnail_url}`. Audio: `POST /audio {extension:'wav'|'mp3'|'webm', name}`.
2. `fetch(upload_url, {method:'PUT', body, headers:{'Content-Type', Origin}})` — must be 200 (“Failed to upload file to storage”). Image is orientation-fixed/compressed client-side first (`skipOrientationFix:{maxSizeMb:10}`).
3. Confirm: `POST /media/{id}/upload {job_id, filename, force_nsfw_check:true, force_ip_check, surface}`; video `POST /video/{id}/upload?start_seconds=&end_seconds= {filename, force_nsfw_check, force_ip_check, surface}`; audio `POST /audio/{id}/upload`. Response `{id, status:'uploaded'|'nsfw'|'ip_detected', ip_check_finished}`; 422 `detail.error_type: 'nsfw'|'ip_detected'`.
4. If `ip_check_finished` false, client polls `GET` media status (`/media/status`, batch `/jobs/status-batch` for `_job` assets) up to N times.
Media reference in job params: `{id, url, type:'media_input'|'video_input'|'audio_input'|'image_job'|...}`; in v2 params as `medias:[{role:'start_image'|'end_image'|'image'|'video'|'audio', data:{...}}]`.

Large files (`sS_zlQzzOmlYCxIY`): **Uppy + @uppy/aws-s3** (`shouldUseMultipart`, `limit:5`), backed by `POST /uploads/multipart/init` (→ `upload_id, part_size, part_count`; client asserts part_size ≥ 5 MiB “S3 minimum”), `POST /uploads/multipart/part-urls`, `POST /uploads/multipart/complete {parts:[{part_number, etag}]}`, `POST /uploads/multipart/abort`. Size limits table: single-PUT `{media_input:50MB, video_input:100MB, audio_input:100MB, file_input:100MB}`, max `{media_input:100MB, video_input:1000(×Ee), audio_input:500MB, file_input:1(×Ee)}` (Ee INFERRED = GB). Upload host: presigned S3 (bucket/host UNKNOWN — returned by server; error text references “ExposeHeaders CORS config on the upload domain”). Transient 502/503/504 retried (`pe()` + retry wrapper `O(...)`).

### 2.3 Status & completion detection — OBSERVED

`BEH3aS1SbvrZOWAb` (job status store):
- SSE: `x.pool.allocate(https://fnf-api-gw.higgsfield.ai/fnf-notification/notifications/stream)` (`TDHytUTtJ6Q_6Q_8`), `subscribe('job:status_changed', y)`; EventSource-based with token provider, reconnect/backoff, 401/403 force token refresh (`pnaLFEMlpfjwhvp7`).

- UI phase mapping (`Y01HIu8l…` `W()`): `completed`; `failed|nsfw|ip_detected`→failed; `canceled`; `queued|pending|waiting`→queued; else in_progress. Pipeline sub-statuses for agentic products: `ip_detect, dna, script, visuals, vision, flow`.
- Terminal sets (`df`): `failed, nsfw, canceled, cancelled, timed-out, timed_out`; active (`uf`): `queued, in_queue, in_progress, running, waiting, processing`.
